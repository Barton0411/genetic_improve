# 接口复合项目本地补充牧场

## 适用范围

“添加本地牧场”仅出现在“伊起牛接口牧场”和“慧牧云接口牧场”页面，用于把接口清单中缺失的牧场加入同一个复合项目。

原有“数据上传”Tab继续服务于本地上传的伊起牛、慧牧云和优源-DC305单牧场项目，不增加该入口。

## 操作流程

1. 用户先在接口牧场页面点击“添加本地牧场”。
2. 选择本地文件格式：伊起牛、优源-DC305或慧牧云。
3. 上传母牛信息，并可选上传配种记录。母牛信息必填，配种记录选填。
4. 系统复用现有单牧场上传规则完成校验和标准化。
5. 处理成功后，本地牧场与接口牧场一起显示、勾选、预览和创建项目。

## 业务约束

- 一个复合项目至少包含一个当前接口数据源的牧场，不能只使用本地补充牧场创建。
- 本地牧场编号不能与接口牧场或其他本地补充牧场重复。
- 切换伊起牛/慧牧云接口时，会清空当前选择和本地暂存数据。
- 复合项目给牛号、母号和配种记录牛号添加牧场编号前缀，避免跨牧场重号。
- 项目元数据记录接口/本地来源、文件格式、母牛数量和配种记录数量。
- 自动生成报告时，本地配种记录参与当前数据源支持的已配公牛和近交分析。

## 窗口行为

“创建项目并自动生成报告”的进度窗口以应用主窗口为父窗口，使用窗口级模态并居中显示；任务完成或取消前始终位于主窗口上方。
