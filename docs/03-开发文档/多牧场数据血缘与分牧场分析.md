# 多牧场数据血缘与分牧场分析

## 目标

伊起牛和慧牧云使用同一套牧场来源字段。单牧场和多牧场项目均保留：

- `牧场编号`
- `牧场名称`

牧场编号按文本处理，禁止出现小数后缀或科学计数法。多牧场项目优先使用接口原始
`farmCode`；旧项目缺失时，可根据 `project_metadata.json` 中的牧场编号与带前缀牛号
进行回填。

## 数据链

牧场来源字段从原始牛群、配种记录进入标准化数据，并继续传递到：

- `processed_cow_data_key_traits_final.xlsx`
- `processed_index_cow_index_scores.xlsx`
- `processed_mated_bull_traits.xlsx`
- 母牛、已配公牛和备选公牛的近交及隐性基因分析结果
- 综合 Excel 报告中的牛只级明细工作表

综合报告的总体汇总、图表和 PPT 暂不按牧场拆分。

## 分牧场分析输出

`关键育种性状分析结果.xlsx` 保留原有六个总体工作表，并在多牧场项目中新增：

- `分牧场在群年份汇总`
- `分牧场全部年份汇总`
- `分牧场在群NM$分布`
- `分牧场全部NM$分布`
- `分牧场在群TPI分布`
- `分牧场全部TPI分布`

`系谱识别分析结果.xlsx` 保留原 `Sheet1`，并新增 `分牧场汇总`。

计算用的 `sire_traits_mean_by_cow_birth_year.xlsx` 结构必须保持不变。分牧场结果写入
独立文件 `sire_traits_mean_by_cow_birth_year_by_farm.xlsx`，每个性状一个工作表，
列为牧场编号、牧场名称、出生年份、均值、样本数和是否插值。

已配公牛近交及隐性基因结果在配对明细和异常明细中保留牧场来源；多牧场且存在异常
记录时，新增 `分牧场统计表`。原 `统计表` 保持总体口径。

## 兼容与验收

- 原工作表名称、顺序和总体口径保持不变，现有 Excel/PPT 读取逻辑继续使用总体表。
- 新增字段不得被动态识别为育种性状。
- 同一统计口径下，各牧场头数之和必须等于总体头数。
- 各牧场均值按头数加权后，应与总体均值一致，允许最终显示值产生 0.01 的舍入误差。
- 配种记录数、异常记录数的分牧场合计必须等于总体记录数。
- 牧场编号必须以文本写入 Excel，不得出现 `.0`。
