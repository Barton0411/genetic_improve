# 慧牧云服务端只读代理

## 目的

桌面客户端不得保存、读取或接收慧牧云 AES 原始密钥。慧牧云牛群数据和配种记录统一由 Genetic Improve 认证服务代理读取，用户只使用现有软件账号登录。

## 调用链路

1. 育种中心账号登录时，客户端直接取得软件 JWT。
2. 伊起牛账号登录时，客户端将伊起牛访问令牌提交给
   `POST /api/auth/yqn/exchange`；认证服务调用伊起牛 `getInfo` 核验令牌，
   从可信响应中取得工号，并只对白名单账号签发软件 JWT。
3. 客户端请求 `GET /api/auth/hmy/cows` 或
   `GET /api/auth/hmy/breeding-records`，请求头使用
   `Authorization: Bearer <软件 JWT>`。
4. 认证服务校验软件 JWT，并再次校验慧牧云功能工号白名单。
5. 认证服务从生产环境变量读取慧牧云接口地址和 AES 密钥，生成当天
   `secret` 请求头。
6. 认证服务调用慧牧云 `/outside/yl/cow` 或 `/outside/yl/bred`，
   只向客户端返回对应的分页只读数据。

慧牧云牛群记录同时返回 `farmCode` 和 `farmName`。桌面端下载完整分页数据时必须：

- 校验每条记录的 `farmCode` 与请求编码一致。
- 校验同一次完整下载中的非空 `farmName` 唯一。
- 项目元数据优先使用接口返回的 `farmName`；空数据牧场继续使用本地牧场清单。
- 原始牛群 Excel 输出 `API farmcode`、`牧场名称`、`牧场编号` 三列。
  其中 `牧场编号` 从 `farmName` 开头的七位数字提取，`牧场名称` 不包含该前缀；
  无七位前缀时编号留空、名称原样保留。

## 牧场分类与批量选择

慧牧云牧场编码仍由 `config/hmy_farms.json` 提供。牧场分类来自
“优然牧业牧场类型.xlsx”的“牧场明细”表，经牧场标准名称可靠对应后固化到
`config/hmy_farm_classifications.json`，运行时不依赖用户电脑上的原始 Excel。
该分类表的适用范围仅为优然牧业；赛科星牧场即使与优然牧场同名，也不得按名称
继承优然分类。例如赛科星托县 `1100310009`、清水河 `1100310026` 与优然同名
牧场是不同实体，必须在所有分类维度统一归入“其他”。

客户端支持按以下六个维度切换分组：

- 大区
- 有机(HP)
- 热应激区域
- 牛源模式
- A2
- DHA

无法与分类表可靠对应的牧场，以及任一分类字段为空的牧场，在该分类维度中
统一归入“其他”。不得根据牧场名称或地名猜测分类。

本地牧场清单用于下载前展示和空数据牧场兜底。只要牛群接口返回非空
`farmName`，项目创建后的牧场名称应以接口返回值为准。

每个慧牧云分类组均可整组全选或取消。伊起牛保持“大区/区域”两级结构，
大区节点和区域节点均可整组全选或取消；批量操作只影响当前分组，不清除其他
分组已经选择的牧场。

## 配种记录

慧牧云配种接口当前返回 `farmCode`、`farmName`、`cowId`、`siren` 和
`eventDate`。桌面端必须：

- 分页取得接口报告的全部记录，并验证实际数量等于 `count`。
- 校验每条记录的 `farmCode` 与请求编码一致，同一次完整下载中的非空
  `farmName` 唯一。
- 拒绝牛号、冻精号或配种日期为空的记录，避免静默生成不完整分析。
- 多牧场合并时只给配种记录牛号增加 API farmcode 前缀；冻精号不得加前缀。
- 原始配种 Excel 保留 `API farmcode`、`牧场名称`、`牧场编号` 三列；
  标准化后的内部牧场归属使用 API farmcode。

当前接口没有返回“是否性控”。网站历史下载数据表明，冻精号中的 `XK`、
`551` 等标记与“是否性控”字段并非始终一致，因此接口配种记录的冻精类型
统一标记为“未知”，不得根据冻精号静默猜测。已配公牛性状、近交和隐性基因
分析仍可使用牛号、配种日期和冻精号正常执行；涉及冻精类型的汇总应明确显示
“未知”。若上游将来提供明确性控字段，再按该字段转换。

网站按某个牧场下载的历史事件文件可能包含“所在牧场”为其他牧场的转场历史
记录；`/outside/yl/bred` 按事件归属 farmCode 返回。软件按接口 farmCode
口径合并，不把其他牧场历史事件错误归入当前牧场。

## 服务端配置引用

- `HMY_API_BASE_URL`：慧牧云接口根地址。
- `HMY_API_AES_KEY`：慧牧云 AES 鉴权值。

上述变量只保存在生产认证服务的受限环境文件中，不得写入代码、文档、日志、安装包或接口响应。

## 接口

`POST /api/auth/yqn/exchange`

请求头携带伊起牛登录返回的 Bearer Token。服务端不信任客户端提交的工号，
必须以伊起牛 `getInfo.user.userName` 为准：

- 伊起牛令牌失效或无法核验：返回 401。
- 工号不在慧牧云功能白名单：返回 403。
- 核验成功：返回短期软件 JWT，原伊起牛令牌不写入日志或本地缓存。

`GET /api/auth/hmy/cows`

查询参数：

- `farmCode`：牧场编码，必填。
- `pageSize`：每页数量，范围 1–2000，默认 2000。
- `pageNum`：页码，从 1 开始。

访问控制：

- 无有效 JWT：返回 401。
- 工号不在慧牧云功能白名单：返回 403。
- 服务端慧牧云配置缺失：返回 503。
- 慧牧云上游不可用或响应异常：返回 502。

`GET /api/auth/hmy/breeding-records`

查询参数：

- `farmCode`：牧场编码，必填。
- `pageSize`：每页数量，范围 1–10000，默认 10000。
- `pageNum`：页码，从 1 开始。

访问控制和错误映射与牛群接口一致。服务端仅执行慧牧云
`GET /outside/yl/bred`，不提供任何写入能力。

## 部署与回滚

生产服务为 `genetic-auth-api.service`，工作目录为
`/home/ecs-user/genetic_improve_auth_v2`。部署文件为 `auth_api.py`、
`hmy_proxy.py` 和 `yqn_auth_bridge.py`。

部署前必须备份现有代码和环境文件；部署后依次验证：

1. systemd 服务为 active。
2. `/health` 返回 200。
3. 真实伊起牛令牌可换取软件 JWT，失效令牌返回 401。
4. 非白名单 JWT 请求返回 403。
5. 白名单 JWT 可通过代理取得一页真实牛群数据和一页真实配种记录。
6. 使用同一牧场、同一日期范围核对牛号、配种日期和冻精号。
7. 日志和响应中不出现 AES 密钥、伊起牛令牌或软件 JWT 原值。

桌面端主日志使用 20MB 单文件、最多 5 个备份的轮转策略；伊起牛
`getInfo` 只记录响应结构摘要，不记录原始用户资料。

回滚时恢复部署前备份的 `auth_api.py` 和环境文件，移除新增模块后重启认证服务。
