# 奶牛品种过滤与母牛近交分析

> 维护者：王波臻/Barton
> 创建日期：2026-06-16

本文档记录三项需求的实现：Excel 报告除法报错修复、所有育种分析仅统计奶牛母牛、母牛自身近交系数计算与缓存机制。

## 一、Excel 报告除法报错修复

**问题**：生成报告时报错 `ufunc 'divide' not supported for the input types ... casting rule 'safe'`。

**根因**：已用公牛性状明细的性状列为 object dtype（含字符串/空值），加权平均除法时 numpy 无法对 object 类型做除法。

**修复**：
- `core/excel_report/sheet_builders/sheet9_builder.py`：加权平均前对性状列、使用次数 `pd.to_numeric(errors='coerce')`，并防除零。
- `core/excel_report/data_collectors/used_bulls_detail_collector.py`、`used_bulls_summary_collector.py`：求均值前转数值，从源头消除 object dtype。

## 二、所有育种分析仅统计奶牛母牛（排除公牛 + 肉牛品种）

**需求**：所有育种分析只针对奶牛母牛，排除公牛（sex=='公'）和肉牛品种（西门塔尔、安格斯、和牛等）。

**统一过滤函数**：`config/breed_constants.py`
- `DAIRY_BREEDS`：奶牛品种白名单（荷斯坦、娟姗、娟珊、瑞士褐、更赛、爱尔夏）。
- `is_dairy_breed(breed)`：判断单个品种是否为奶牛（空值按奶牛/荷斯坦处理）。
- `filter_dairy_cows(df)`：同时排除公牛和肉牛品种，返回奶牛母牛子集。

**过滤点**（采用派生层过滤，不动源头 `processed_cow_data.xlsx`）：
| 位置 | 作用 |
|------|------|
| `core/breeding_calc/traits_calculation.py`（读 processed_cow_data 后） | 性状派生文件统一过滤，下游性状/指数/系谱完整性/选配/报告自动只剩奶牛 |
| `core/breeding_calc/index_calculation.py` `calculate_cow_traits` | 指数备用直读路径保险过滤 |
| `core/breeding_calc/generate_pedigree_analysis.py` / `pedigree_analysis.py` | 系谱完整性按品种过滤 |
| `core/inbreeding/inbreeding_page.py` 已配/备选分析 | 近交分析过滤（已配按母牛档案建奶牛白名单过滤配种记录） |

**重要区分**：代码里的"肉牛冻精"是**配种方式**（荷斯坦奶牛也能用肉牛冻精配种），与"母牛是否肉牛品种"无关。过滤严格使用 `breed` 品种字段（`is_dairy_breed`），不用字符串"肉牛"匹配，不影响肉牛冻精配种逻辑。

**存栏统计例外**：牧场存栏/在群头数照实统计全部牛只（含肉牛），不过滤。
- `core/excel_report/data_collectors/farm_info_collector.py`：新增 `breed_composition`、`dairy_count`、`beef_count` 字段。
- `core/excel_report/sheet_builders/sheet1_builder.py`：存栏合计行后增加品种构成说明（"注：在群X头中，奶牛X头、肉牛X头；以下育种相关分析仅统计奶牛品种"），仅当存在肉牛时显示。

## 三、母牛近交分析（自身近交系数 + 缓存 + 清空）

**问题**：母牛本身近交系数此前被硬编码为 0.0%，从未真实计算。

**修复**：`core/inbreeding/inbreeding_page.py`
- `calculate_inbreeding_coefficients`：每条记录用 `PathInbreedingCalculator.calculate_inbreeding_coefficient(cow_id)`（与后代预测同一套 Wright 通径法）计算母牛自身近交系数，回写 `近交系数` 列。

**新增"母牛近交分析"按钮**：在已配/备选公牛分析左侧，三个分析按钮并排。
- `analyze_cow_self(project_path)`：计算每头奶牛母牛的自身近交系数，生成结果。

**缓存机制（算一次后直接展示）**：
- 三个分析改用**固定文件名**（覆盖式），见 `RESULT_FILENAMES`：
  - 母牛近交分析 → `母牛近交系数分析结果.xlsx`
  - 已配公牛分析 → `已配公牛_近交系数及隐性基因分析结果.xlsx`
  - 备选公牛分析 → `备选公牛_近交系数及隐性基因分析结果.xlsx`
- `start_analysis` 开头检测固定文件是否存在，存在则 `load_cached_results` 直接加载展示，不重算。
- 报告 collector（`breeding_inbreeding_collector.py`、`candidate_bulls_genes_collector.py`）glob 模式改为兼容固定名与历史时间戳名，按文件修改时间取最新。

**清空按钮**：每个分析各配一个红色"清空"按钮（`clear_analysis`），删除对应固定文件及历史时间戳旧文件后清空表格，下次点击重新计算。

## 验证方式

手动运行应用，进入近交分析页面：
1. 系谱完整性、性状、指数等报告中肉牛/公牛不计入。
2. 母牛自身近交系数显示真实值（非全 0）。
3. 首次点三个分析按钮计算并生成 Excel；再次点直接展示；点清空后可重算。
4. Excel 牧场概况页存栏处显示品种构成说明。
